# Алгоритм Хорспула (Задача B — Варіант 26)

Лабораторна робота з дисципліни **«Алгоритми та складність» (АтаС)**.  
Реалізація алгоритму пошуку підрядка у тексті за **алгоритмом Боєра–Мура–Хорспула** мовою C++.

---

## Опис задачі

Задано три вхідні файли в директорії `data/`:

- `text.txt` — текст $T$ довжиною близько $1\,000\,000$ малих латинських літер;
- `pattern.txt` — зразок $P$ для пошуку (`xfyxnffkyynkkyfx`, довжина $m = 16$);
- `chars.txt` — чотири контрольні символи через пробіл (`x f k c`).

Програма повинна вивести три рядки:
1. Кількість входжень зразка $P$ у тексті $T$.
2. Кількість прикладань (кількість позицій зразка відносно тексту, на яких виконувалося порівняння).
3. Значення таблиці зсувів `shift` для чотирьох символів із `chars.txt` у тому самому порядку через пробіл.

Повна умова завдання міститься у файлі [`docs/B. Хорспул.pdf`](docs/B.%20Хорспул.pdf).

---

## Алгоритм

### 1. Побудова таблиці зсувів (`buildShiftTable`)
Нехай $m$ — довжина зразка $P$. Для кожного символу $c$ (ASCII, `0..255`):
- Якщо $c$ трапляється серед перших $m - 1$ символів зразка $P[0 \dots m - 2]$, то  
  $$\text{shift}[c] = m - 1 - j$$
  де $j$ — **найбільший індекс** серед $0 \dots m - 2$, для якого $P[j] = c$.
- Інакше $\text{shift}[c] = m$.

Останній символ зразка $P[m - 1]$ не враховується у формулі зсуву, щоб уникнути нульового зсуву та зациклення.

### 2. Пошук (`horspoolSearch`)
Зразок початково прикладається на позиції $s = 0$ (кінець зразка на позиції $i = m - 1$). Поки $i \le n - 1$:
1. Збільшується лічильник прикладань (`alignments++`).
2. Зразок порівнюється з фрагментом тексту $T[i - m + 1 \dots i]$ справа наліво.
3. Якщо всі $m$ символів збіглися — фіксується входження (`matches++`).
4. Виконується зсув на $\text{shift}[T[i]]$ — за символом тексту, що стоїть навпроти **останнього** символу зразка (це правило діє як після незбігу, так і після знайденого входження).

### Оцінка складності
- **Часова складність:**
  - Побудова таблиці зсувів: $O(m + |\Sigma|)$, де $|\Sigma| = 256$.
  - Пошук: у середньому $O(n / m)$ (сублінійна), у найгіршому випадку $O(n \cdot m)$.
- **Просторова складність:** $O(|\Sigma|)$ на таблицю зсувів + пам'ять для зберігання вхідного тексту $O(n)$.

## Збірка та запуск

### Через Visual Studio (Windows)
1. Відкрийте рішення [`src/Horspool/Horspool.sln`](src/Horspool/Horspool.sln) у Visual Studio.
2. Оберіть конфігурацію `Debug` або `Release` (`x64`).
3. Натисніть **Ctrl + F5** (Запуск без налагодження).

> **Примітка щодо шляхів:** у коді використовуються відносні шляхи `../../../data/*.txt`, розраховані на запуск із робочої директорії проєкту `src/Horspool/Horspool/` (стандартна робоча директорія Visual Studio).

### Через командний рядок (після компіляції)
```powershell
cd src/Horspool/Horspool
..\x64\Debug\Horspool.exe
```
